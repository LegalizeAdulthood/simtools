NAME
       macro7 - a PDP-7 assembler


SYNOPSIS
       macro7 [ -d -p -m -r -x ] inputfile inputfile...


DESCRIPTION
       This is a cross-assembler for PDP-7 assembly language programs. It pro-
       duces  an output file in RIM format only. A listing file is always pro-
       duced, with optional symbol table and/or symbol  cross-reference  (con-
       cordance).  The permanent symbol table can be output in a form that may
       be read back in, allowing for a customized permanent symbol table.  Any
       detected  errors are output to a separate file, including the filename,
       line number, column number, and error message, as well as  marking  the
       error in the listing file.

       The following file name extensions are used:

       .7     source code (input)

       .lst   assembly listing (output)

       .rim   assembly output in DEC's RIM format (output)

       .err   assembly errors detected (if any) (output)

       .prm   permanent  symbol table in a form suitable for reading after the
              EXPUNGE pseudo-op.


OPTIONS
       -d     Dump the symbol table at the end of assembly.

       -p     Generate a file with the permanent symbols in it.  (To  get  the
              current  symbol  table,  assemble  a file that has only START in
              it.)

       -x     Generate a cross-reference (concordance) of user symbols.


DIAGNOSTICS
       Assembler error diagnostics are output to an error file and inserted in
       the listing file. Each line in the error file has the form:
       <filename>(<line>:<col>) : error: <message> at Loc = <loc>

       An example error message is:
       bintst.7(17:9) : error: undefined symbol "UNDEF" at Loc = 07616

       The error diagnostics in the listing start with a  two-character  error
       code  (if appropriate) and a short message. A caret '^' is placed under
       the item in error if appropriate. An example error message is:
       17 07616 3000          DAC     UNDEF
       UD undefined                  ^
       18 07617 1777          TAD  I  DUMMY

       When an indirect is generated, an at character '@' is placed after  the
       instruction value in the listing as an indicator as follows:
       14 03716 1777@         TAD     OFFPAG

       Undefined  symbols are marked in the symbol table listing by prepending
       a by prepending a '#' to the symbol. Examples are:
       #REDEF   04567
        SWITCH   07612
       ?UNDEF   00000

       Refer to the code for the diagnostic messages generated.
